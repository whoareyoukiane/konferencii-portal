## Найденные ошибки и исправления

| Ошибка | Исправление | Коммит |
|---|---|---|
| Логин `Admin` регистрировался рядом с `admin` | поиск логина без учёта регистра и уникальный индекс в базе (миграция 005) | «логин теперь не различает регистр» |
| Пароль из 8 пробелов принимался сервером (браузер его не пропускал) | проверка на пробелы в `Validator`, в браузере пароль больше не обрезается | «проверка пароля и телефона» |
| Телефон `+7 900 123-45-67 abc` принимался, буквы отбрасывались | разрешены только цифры, пробелы, плюс, скобки и дефис | «проверка пароля и телефона» |
| Пароли длиннее 72 байт обрезались хешированием: любое окончание подходило | пароль не длиннее 72 байт, ошибка с подсказкой | «проверка пароля и телефона» |
| Заявку на мероприятие 18.12.2026 можно было завершить 3 ноября | при завершении проверяется дата мероприятия | «заявку нельзя завершить до даты мероприятия» |
