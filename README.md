# Конференции.РФ

Учебный портал для приёма заявок на участие в конференциях. МДК.09.01 «Проектирование и разработка веб-приложений», Котлов Арсений Михайлович.

PHP 8.4 без фреймворков, база SQLite через PDO, HTML, CSS и немного JavaScript.

## Запуск

Нужен PHP 8.2 или новее с расширениями `pdo_sqlite`, `sqlite3`, `mbstring` (в папке `portal` лежит `php.ini` с ними).

```
cd portal
php -c php.ini db/migrate.php
php -c php.ini db/seed.php
php -c php.ini -S localhost:8080 -t public
```

Сайт открывается на http://localhost:8080. Проверка правил ввода: `php -c php.ini tests/run.php`.
