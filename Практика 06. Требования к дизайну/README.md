# Практика 6. Требования к дизайну веб-приложения

Портал «Конференции.РФ». Выполнил Котлов Арсений Михайлович.

## Предметная область и аудитория

Портал нужен организатору конференций: заявки приходят в одном месте, а не в почте и мессенджерах.

| Группа | Кто | Как заходит | Что важно |
|---|---|---|---|
| Участники | студенты и специалисты 18-45 лет, чаще из ИТ | с телефона по дороге и с ноутбука на работе | подать заявку за 1-2 минуты, видеть статус |
| Администраторы | 2-3 сотрудника организатора | с компьютера, весь день | быстро найти заявку, увидеть данные участника, сменить статус |

Из этого следует:
- форма заявки короткая, три выбора из списков и одна кнопка;
- на телефоне всё должно работать так же, как на компьютере;
- у администратора на экране много заявок, поэтому нужны фильтры и чёткие карточки.

## Корпоративный стиль

Готового стиля у заказчика нет (логотипа, брендбука). Поэтому задаю свой и в дальнейшем держусь его.

| Элемент | Решение |
|---|---|
| Название | Конференции.РФ, в логотипе «.РФ» выделено акцентным цветом |
| Настроение | деловое, спокойное, без кричащих эффектов |
| Основной цвет | тёмно-синий `#0f1b2d` (шапка, заголовки) |
| Фирменный цвет | бирюзовый `#0e7c86` (кнопки, ссылки) |
| Акцент | янтарный `#f2b134` (бейджи, выделение «.РФ») |
| Фон | светло-серый `#f4f6f8`, карточки белые |
| Ошибка и успех | красный `#b3261e`, зелёный `#2e7d4f` |
| Шрифты | Rubik для заголовков, Source Sans 3 для текста; оба с кириллицей |
| Картинки | реальные фотографии конференций, без иллюстраций |
| Форма элементов | карточки со скруглением 10 px, кнопки со скруглением 8 px |

## Страницы для дизайна

1. Регистрация
2. Авторизация
3. Просмотр заявок (список заявок участника)
4. Создание заявки
5. Панель администратора
6. Личный кабинет

Кроме них нужны главная, список мероприятий и страницы ошибок 403 и 404.

## Требования к страницам

| Страница | Что на странице | Требования к дизайну |
|---|---|---|
| Регистрация | четыре поля (логин, почта, телефон, пароль), кнопка, ссылка на вход | подпись над каждым полем, ошибка красным текстом под полем и красная рамка, подсказка в поле телефона |
| Авторизация | два поля, кнопка, ссылка на регистрацию | общая ошибка над формой, форма по центру, не шире 460 px |
| Просмотр заявок | карточки: статус, мероприятие, дата, помещение, оплата, номер | статус цветным бейджем, новые заявки сверху, если заявок нет, подсказка и кнопка «Новая заявка» |
| Создание заявки | три списка: мероприятие, помещение, способ оплаты | выпадающие списки, мероприятие выбрано, если пришли с карточки, кнопка на всю ширину на телефоне |
| Панель администратора | фильтры (статус, мероприятие), счётчик, карточки с данными участника | фильтры в одну строку, кнопки «Назначить» и «Завершить» главные, «Удалить» отличается красным цветом |
| Личный кабинет | логин, почта, телефон, роль, число заявок, ссылка на заявки | строки «название: значение», на телефоне в один столбец |
| Главная | крупный блок с фото и кнопкой, три ближайших мероприятия | фото на всю ширину, на телефоне фото ниже заголовка |
| Список мероприятий | карточки с фото, датой, местом, описанием, кнопкой | три колонки на компьютере, одна на телефоне |

## Общие требования

- Адаптивность: ширины 390, 768 и 1280 px, горизонтальной прокрутки нет.
- Кнопки и поля не ниже 44 px по высоте, чтобы попасть пальцем.
- Контраст текста с фоном не ниже 4,5 к 1.
- Меню на телефоне прячется за кнопку.
- Картинки сжаты, шрифты лежат на сайте, лишних библиотек нет.

## Результат

Описал аудиторию, фирменный стиль и требования к шести страницам плюс общие требования. По этому документу делаю мобильные макеты (практика 8) и вёрстку (практика 10).
