# Практика 3. Разработка модулей ИС по ТЗ

Выполнил Котлов Арсений Михайлович. Код лежит в папке `portal`.

## Стек и структура

PHP 8.4 без фреймворков, база SQLite через PDO (MySQL на компьютере нет, а SQL у них общий, поэтому перейти на MySQL можно сменив строку подключения). Разделил проект на три части:

| Часть | Папка | Что там |
|---|---|---|
| Фронтенд | `portal/views`, `portal/public` | шаблоны страниц, стили, картинки |
| Бэкенд | `portal/src` | классы: контроллеры и репозитории |
| База данных | `portal/db` | миграции, скрипт миграции, тестовые данные |

Все запросы идут через `public/index.php`: он смотрит адрес и вызывает нужный метод контроллера.

## Классы (ООП)

| Класс | За что отвечает |
|---|---|
| `Database` | одно подключение к базе |
| `UserRepository`, `EventRepository`, `RequestRepository` | запросы к таблицам |
| `Validator` | проверка логина, пароля, почты и телефона |
| `Auth` | вход и выход, кто сейчас вошёл |
| `Controller` | общий предок: показ страницы, переход, проверка входа |
| `AuthController`, `RequestController`, `AdminController`, `PageController` | модули системы |

## Модули

| Модуль | Что сделано |
|---|---|
| Регистрация | логин (3-20 символов, латиница, цифры, «_», уникальный), пароль от 8 символов, почта по шаблону, телефон приводится к виду +7XXXXXXXXXX |
| Авторизация | вход по логину и паролю, сообщение «Неверный логин или пароль», выход |
| Создание заявки | мероприятие, помещение и способ оплаты из списков; на прошедшее мероприятие и на то же второй раз подать нельзя |
| Просмотр заявок | участник видит только свои заявки со статусом |
| Панель администратора | все заявки, фильтр по статусу и мероприятию, смена статуса по порядку (новая, назначено, завершено), удаление |
