# Практика 8. Дизайн с учётом современных тенденций, мобильные макеты

Выполнил Котлов Арсений Михайлович.

## Тенденции, которые взял

| Тенденция | Что сделал на макетах |
|---|---|
| Минимализм | один акцентный цвет на экране, мало рамок и линий, много воздуха между блоками |
| Карточный дизайн | мероприятия и заявки в белых карточках с мягкой тенью и скруглением 12 px |
| Микро-взаимодействия | кнопка при нажатии чуть уменьшается и темнеет, у полей заметная обводка при фокусе, красная рамка и подпись при ошибке |
| Мобильные привычки | нижнее меню из трёх пунктов (его достаёт большой палец), крупные поля и кнопки высотой 48 px |

Источники, откуда брал идеи: приложения билетных сервисов и расписания конференций (карточки, нижняя навигация). Своими словами, без копирования.

## Макеты

Отдельные .html-файлы для мобильной версии лежат в папке `mobile`, ширина рассчитана на 390×844 px.

| Файл | Страница | Скриншот |
|---|---|---|
| `mobile/index.html` | главная и ближайшие мероприятия | `01_index.png` |
| `mobile/request.html` | создание заявки | `02_request.png` |
| `mobile/requests.html` | список моих заявок | `03_requests.png` |
| `mobile/login.html` | вход (показано состояние ошибки поля) | `04_login.png` |

Стили общие для всех страниц в `mobile/mobile.css`, шрифты те же, что в портале (Rubik и Source Sans 3), цвета из практики 6.

## Оптимизация графики

Фотографии с pexels.com обрезал и сжал под двойную плотность экрана (780 px по ширине, что вдвое больше ширины телефона), формат JPEG с прогрессивной загрузкой.

| Файл | Было | Стало |
|---|---|---|
| `hero.jpg` (главная) | 195 КБ (1400 px по ширине) | 62 КБ (780×520) |
| `event-1.jpg` | 146 КБ | 37 КБ |
| `event-2.jpg` | 223 КБ | 52 КБ |

Всего картинки главной страницы весят около 151 КБ вместо 564 КБ. Шрифты подключены с `font-display: swap`, чтобы текст появлялся сразу.

## Проверка на смартфоне

Настоящего смартфона под рукой не было, поэтому смотрел в Chrome в режиме эмуляции устройства 390×844 (скриншоты сняты в нём). Горизонтальной прокрутки нет, нижнее меню не закрывает контент (у страниц отступ снизу 72 px), текст читается без увеличения.

## Результат

Четыре мобильных макета в .html, картинки сжаты примерно в 3,7 раза, дизайн следует выбранным тенденциям.
