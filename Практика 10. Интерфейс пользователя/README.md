# Практика 10. Разработка интерфейса пользователя

Выполнил Котлов Арсений Михайлович. Верстка в `portal/views` и `portal/public`.

## Что сделано

Свёрстал страницы по требованиям из практики 6 и мобильным макетам из практики 8: главная, мероприятия, регистрация, вход, создание заявки, мои заявки, личный кабинет, панель администратора, страницы 403 и 404. Использовал HTML и CSS без библиотек, JavaScript только для меню на телефоне (`public/js/menu.js`) и проверки форм (`public/js/validate.js`).

| Что | Решение |
|---|---|
| Стили | один файл `public/css/style.css`, цвета и размеры в переменных `:root` |
| Шрифты | Rubik и Source Sans 3 лежат на сайте (`public/fonts`), без запросов к чужим серверам |
| Картинки | реальные фото с pexels.com, обрезаны и сжаты, у каждой заданы `width` и `height`, чтобы страница не прыгала при загрузке (источники в `public/img/ИСТОЧНИКИ.txt`) |
| Статусы | бейджи цветом: новая бирюзовая, назначено жёлтая, завершено зелёная |
| Форма | подпись над полем, ошибка красным под полем, красная рамка поля |

## Адаптивность

Два порога в CSS: до 860 px главная складывается в одну колонку, до 640 px меню прячется за кнопку «Меню», карточки идут по одной, кнопки на всю ширину.

Проверил в Chrome в режиме телефона 390×844 на всех страницах. Ширина содержимого везде равна ширине экрана (390 из 390), то есть горизонтальной прокрутки нет. Скриншоты `m1` - `m7`.

## Кроссбраузерность

| Браузер | Версия | Результат |
|---|---|---|
| Google Chrome | 156 | все страницы верно, скриншоты `01` - `09` |
| Microsoft Edge | 155 | главная и панель администратора выглядят так же (`10_glavnaya_edge.png`, `11_admin_edge.png`) |

Firefox и Safari на компьютере не установлены, в них не проверял. Chrome и Edge на одном движке, поэтому полной проверкой это не считаю.
